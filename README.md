# DrsClaudeTools

Claude Code mods (plugins) by DrStevenWright, published as a plugin marketplace.

| Mod | What it does |
| --- | --- |
| [unreal-mcp](plugins/unreal-mcp) | Helps connect Claude Code to Unreal Editor's MCP server and displays current connection status. |
| [prompt-drafter](plugins/prompt-drafter) | Side pane for drafting and formatting prompts before sending them to the prompt box (experimental). |
| [git](plugins/git) | Git tools pane and slash commands to stage, commit, split, publish and tidy up git branches, following each repo's own workflow rules. |
| [parked-items](plugins/parked-items) | Park follow-up work from any chat and track it in a dedicated side pane. |

## Installing a mod

At the prompt of a terminal Claude Code session:

```
/plugin install <mod> --marketplace DrStevenWright/DrsClaudeTools
```

Answer `y` to add the marketplace, then pick a scope. From a shell:

```
claude plugin install <mod> --marketplace DrStevenWright/DrsClaudeTools
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `DrStevenWright/DrsClaudeTools`, then Add plugin.
